# Authentication and PWA deployment checklist

This source change does not modify Supabase or any deployed environment.

- Configure `POURGRID_SUPABASE_URL` and `POURGRID_SUPABASE_ANON_KEY` as protected Netlify build variables. Never expose a service-role key.
- Enable the approved Supabase email OTP/magic-link provider.
- Set the Supabase Site URL to the approved Alpha origin during the controlled Alpha release.
- Allow the Alpha callback URL and the local development callback URL. Use the current origin/path generated by the client.
- Decide and approve a constrained PR-preview redirect strategy before entering real credentials in previews. Wildcard preview redirects should not be enabled casually.
- Email links return to the requesting environment path, complete PKCE session exchange, and then load RLS-protected membership/location context.
- Expired or invalid sessions fail closed and return to sign-in.
- Verify membership, location, and role provisioning separately. A valid session without that context shows Access pending.
- Confirm `/manifest.webmanifest`, all icons, and `/sw.js` return the expected content types after deployment.
